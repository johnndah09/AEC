Professional School Management System for Cameroon Secondary Schools

Comprehensive solution for student enrollment, attendance tracking, academic results, fee collection, and teacher salary management with automatic absence-based deductions

Key Features

📊

Dashboard Overview

Real-time statistics, KPI cards, and recent activities tracking with quick access to all operations.

✓

Attendance Tracking

Mark and monitor student and teacher attendance with automatic percentage calculations and reports.

📝

Student Enrollment

Register students from Form 1 to Upper 6 with support for multiple specializations (Science, Arts, Commercial).

📈

Academic Results

Enter exam results, track performance, generate transcripts, and analyze academic progress by term.

💳

Fee Management

Record payments, track outstanding balances, identify delinquent accounts, and generate financial reports.

👨‍🏫

Teachers Management

Maintain teacher profiles, qualifications, assignments, and track performance with attendance monitoring.

💰

Salary Processing

Automated monthly salary calculation with automatic 1% deduction per day of absence (max 5% monthly).

📄

Comprehensive Reports

Generate attendance, academic, financial, and payroll reports in PDF format for management review.

🎨

Professional Design

Clean, intuitive interface with school colors (skyblue and white) optimized for all devices.

Quick Installation

Option 1: GitHub Pages (Recommended)

Deploy directly to GitHub Pages for free hosting:

git clone https://github.com/yourusername/ambassadors-sms.git cd ambassadors-sms # Push to your repository and enable GitHub Pages in settings

Option 2: Local Installation

Run on your local machine:

# Using Python 3 python -m http.server 8000 # Using Node.js npm install -g http-server http-server

Then open: http://localhost:8000

Option 3: Web Server Deployment

Upload to any web server (FTP/File Manager):

# Upload school_management_system.html to your web server # Access via: https://yourdomain.com/school_management_system.html

Option 4: Docker

Deploy using Docker:

docker pull nginx:latest docker run -p 80:80 -v ./school_management_system.html:/usr/share/nginx/html/index.html nginx
