# 🚀 Quick Start Guide

Get AMBASSADORS SMS live on GitHub in 5 minutes!

---

## ⚡ 5-Minute Deployment

### Step 1: Fork the Repository (1 min)
```
1. Visit: https://github.com/yourusername/ambassadors-sms
2. Click "Fork" button (top right)
3. Wait for completion
```

### Step 2: Clone to Your Computer (1 min)
```bash
git clone https://github.com/yourusername/ambassadors-sms.git
cd ambassadors-sms
```

### Step 3: Enable GitHub Pages (1 min)
```
1. Go to Settings
2. Scroll to "Pages"
3. Select "main" branch
4. Click Save
```

### Step 4: Wait & Visit (2 min)
```
Your site will be live at:
https://yourusername.github.io/ambassadors-sms/
```

## 🐛 Quick Troubleshooting

### Site not loading?
- Wait 2-5 minutes for GitHub to build
- Check "Actions" tab for errors
- Verify GitHub Pages is enabled

### Files not showing?
- Make sure `index.html` is in root folder
- Check capitalization (Linux is case-sensitive)
- Run: `git status` to verify files are tracked

### Styling looks broken?
- Clear browser cache (Ctrl+Shift+Del)
- Check console for CSS errors (F12)
- Verify file paths in HTML
